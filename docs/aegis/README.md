# Aegis Workspace

This directory contains durable planning, baseline, checkpoint, and evidence records for bounded DexDictate work.

- `baseline/` records the verified starting state.
- `plans/` records approved executable plans.
- `work/` records resumable checkpoints and evidence.
- `INDEX.md` links the active records.

These records support review and recovery. They do not replace Git history, tests, or product acceptance.
